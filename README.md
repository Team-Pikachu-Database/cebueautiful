# CebuStays Pages Site

This repository contains only the static CebuStays frontend and images. The backend remains in the private source repository.

The site uses the free GitHub Pages URL:
`https://team-pikachu-database.github.io/cebueautiful/`.

The Actions variable `CEBUSTAYS_API_BASE_URL` points to the Render API at
`https://cebustays-api.onrender.com`. The API must allow requests from
`https://team-pikachu-database.github.io`.

GitHub Pages and Render use different site domains. Browsers may block the
cross-site account session cookie, so sign-in and registration are not
reliable on this free-domain setup. The hotel catalogue does not depend on
that cookie.
